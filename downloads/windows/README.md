# Windows Download

Use `VitaNovaDatabase.exe` as the permanent Windows launch point. The EXE checks `latest.json`, verifies the downloaded JAR with SHA-256, updates `VitaNovaDatabase.jar` when needed, and then starts Vita Nova.

For a new staff computer, place the EXE inside the normal Vita Nova folder with `VitaNovaDatabase.jar`, `update-url.txt`, `VERSION`, `jre`, and the required local config files.
